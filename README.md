## 📌 Sobre o Projeto

O **Manual do Pai Recém-Nascido** é uma aplicação web desenvolvida como uma homenagem e presente especial para o professor Vedilson. O site reúne dicas essenciais, termos engraçados do universo paterno e instruções "de sobrevivência" divididas em seções práticas e divertidas:

- **📦 Manual de Sobrevivência:** Dicionário do bebê, kit de sobrevivência do papai e introdução à nova fase.
- **👶 Operação: Cuidar do pivete:** Passo a passo prático para troca de fraldas, mamadeira, segurança no carro e rotina de sono.
- **👨‍👦 Pai Recém-Nascido:** Brincadeiras sobre a futura grande família do Ved ("Ved de Neve") e mensagens de apoio.

## 🛠️ Tecnologias Utilizadas
